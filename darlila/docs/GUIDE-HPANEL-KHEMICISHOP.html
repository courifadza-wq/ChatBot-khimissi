🔍 Guide visuel hPanel Hostinger — Khemicishop.com

3 réglages à trouver + 1 base de données. Voici TOUS les chemins possibles selon la version de votre hPanel.

⚙️ 1. PHP Version → 8.2 ou 8.3

A

Chemin principal

🏠 hPanel → Sites web → cliquez sur khemicishop.com → tableau de bord → Avancé → Configuration PHP

→ Sélectionnez PHP 8.2 ou PHP 8.3 dans le menu déroulant → Enregistrer

B

Si vous ne trouvez pas "Avancé"

Dans le tableau de bord du site, cherchez un onglet ou bouton « PHP Configuration » ou « PHP Version » — il peut être directement visible sans passer par "Avancé"
C

Cherchez avec la barre de recherche

💡 En haut de hPanel, il y a une barre de recherche 🔍 — tapez « PHP » et cliquez sur « PHP Configuration »

🔑 2. Accès SSH (obligatoire pour déployer)

A

Chemin principal

🏠 hPanel → Sites web → cliquez sur khemicishop.com → tableau de bord → Avancé → Accès SSH

→ Notez : Hôte SSH (ex. srv123.main-hosting.eu), Port (22), Nom d'utilisateur, Mot de passe

B

Si "Accès SSH" n'apparaît pas

Cherchez « SSH » dans la barre de recherche 🔍 de hPanel
Ou regardez dans la colonne de gauche : « Avancé » → « SSH »
⚠️ Si vous ne trouvez vraiment pas SSH, votre plan pourrait ne pas l'inclure. Vérifiez que vous avez le plan Business ou Premium (pas le plan « Single »).
C

Ce que vous devez noter

📝 Copiez-collez ces 3 informations dans un fichier texte :

• Hôte : ex. srv123.main-hosting.eu

• Utilisateur : ex. u123456789

• Mot de passe : (le vôtre)

🌐 3. Sous-domaine : api.khemicishop.com

A

Chemin principal

🏠 hPanel → Domaines (menu de gauche) → Sous-domaines → bouton « Créer un sous-domaine »

→ Tapez : api (Hostinger ajoutera automatiquement .khemicishop.com)

B

Si "Domaines" n'est pas visible

🏠 hPanel → Sites web → Gérer → cherchez « Sous-domaines »
Ou cherchez « sous-domaine » dans la barre de recherche 🔍
C

Après création

✅ Le sous-domaine api.khemicishop.com est créé avec son propre dossier (ex. /domains/api.khemicishop.com/). C'est là que notre script déposera l'API Laravel.

🗄️ 4. Base de données MySQL

A

Chemin principal

🏠 hPanel → Sites web → cliquez sur khemicishop.com → tableau de bord → Bases de données MySQL
B

Créez la base

Cliquez sur « Créer une nouvelle base de données » :

• Nom : khemicishop

• Utilisateur : admin

• Mot de passe : choisissez-en un solide

→ Notez TOUT (le nom complet sera ex. u123456789_khemicishop)

🔒 5. SSL (HTTPS) — après le déploiement

🏠 hPanel → Sécurité → SSL → installez le certificat gratuit pour khemicishop.com ET api.khemicishop.com
⏳ Attendez 5-15 minutes après installation. Le site passera automatiquement en https://
